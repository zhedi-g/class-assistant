# 课堂学习助手

学生向课堂辅助 PWA：实时转写 · 关键词震动提醒 · AI 答疑 · 课后学习包。

## 开发

```bash
pnpm install
pnpm dev        # 局域网可访问，手机连同一 WiFi 打开终端里的 IP
pnpm build      # 类型检查 + 构建
pnpm test:m1    # M1 验收测试（需 dev 运行中）
```
